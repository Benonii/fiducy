# TanStack Start

```bash
npx fiducy init
```

Or by hand: `npm install @fiducy/sdk`, then the files below. The working version is [`examples/tanstack-start`](https://github.com/fiducy-dev/fiducy/tree/main/examples/tanstack-start).

## Server module

```ts title="src/lib/fiducy.ts"
import { createFiducy } from '@fiducy/sdk/server';
import { kyselyStorage } from '@fiducy/sdk/storage/kysely';

import { auth } from '@/lib/auth';
import { pool } from '@/lib/db';

export const fiducy = createFiducy({
  storage: kyselyStorage(pool),
  getUserID: async (request) => {
    const session = await auth.api.getSession({ headers: request.headers });
    return session?.user.id ?? null;
  }
});
```

## Key route

A server route with a splat (`$`) catches every path under `/api/fiducy`:

```ts title="src/routes/api/fiducy/$.ts"
import { toTanStackHandlers } from '@fiducy/sdk/tanstack';
import { createFileRoute } from '@tanstack/react-router';

import { fiducy } from '@/lib/fiducy';

export const Route = createFileRoute('/api/fiducy/$')({
  server: { handlers: toTanStackHandlers(fiducy) }
});
```

The router plugin regenerates `routeTree.gen.ts` when the dev server sees the new file.

## Env

Put the three `FIDUCY_` values in `.env`. Vite loads `.env` into `process.env` for server code; nothing needs a `VITE_` prefix, and Fiducy refuses to run if the app secret has one.

## Widget

```tsx title="src/components/KeySettings.tsx"
import { FiducyKey } from '@fiducy/sdk/react';

export const KeySettings = () => <FiducyKey provider="openai" />;
```

## Model route

```ts title="src/routes/api/chat.ts"
import { createOpenAI } from '@ai-sdk/openai';
import { respondToMissingKey } from '@fiducy/sdk/server';
import { createFileRoute } from '@tanstack/react-router';
import { streamText } from 'ai';

import { fiducy } from '@/lib/fiducy';

export const Route = createFileRoute('/api/chat')({
  server: {
    handlers: {
      POST: async ({ request }) => {
        const settings = await fiducy.providerSettings('openai', { request });
        if (!settings.ok) return respondToMissingKey(settings);
        const { messages } = await request.json();
        const model = createOpenAI(settings).chat('gpt-4o-mini');
        return streamText({ model, messages }).toUIMessageStreamResponse();
      }
    }
  }
});
```

## Notes

- **One Vite:** in a monorepo, keep a single `vite` version. Two copies make TanStack Start answer "Cannot GET /".
- Server functions (`createServerFn`) can call `fiducy.providerSettings(provider, { request: getRequest() })` with `getRequest` from `@tanstack/react-start/server`.
